# bushi4go

卜筮 — Go 六爻/梅花易数排盘引擎，基于 lunar-go。

## 功能

- 64卦排盘（本卦、互卦、变卦）
- 六爻装卦（纳甲、六亲、世应、伏藏、六神）
- 梅花易数起卦（时间 / 数字 / 随机 / 手摇）
- 六爻起卦（时间 / 数字 / 随机 / 手摇）
- 晚子时自动换日（23:00~00:00 归入次日子时）
